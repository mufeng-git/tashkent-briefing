双语精讲 · 语法与生词拆解

UZBEK 实用乌兹语 职场口语 / 协作
Bolalarning ijtimoiy tarmoqlardan foydalanishini cheklash uchun kompleks chora-tadbirlar zarur.
中文翻译：要限制儿童使用社交网络，必须采取综合治理举措。
语法拆解 · GRAMMAR BREAKDOWN
句中 Bolalarning ... foydalanishini 为属格与从属短语，-ning 表所属，foydalanish（使用，动名词）加上所有格词缀 -i 及宾格 -ni 充当宾语；cheklash uchun 中 uchun 为后置词，表示“为了……目的”；谓语 zarur 表示“必要的/必须的”。

ENGLISH 商务英语 商务沟通 / 进度对齐
Local inference engines optimized for tool calling significantly reduce latency for on-device coding agents.
中文翻译：针对工具调用进行优化的本地推理引擎显著降低了端侧代码智能体的执行延迟。
句型与用法解析 · USAGE & STRUCTURE
句子主语为 Local inference engines，过去分词短语 optimized for tool calling 作为后置定语修饰主语；谓语为动词 reduce；significantly 为程度副词；宾语核心词是 latency，介词短语 for on-device coding agents 标明受影响对象。
