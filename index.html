UZBEK 实用乌兹语 职场口语 / 协作
Toshkent aeroportida yangi telefonlarni bojxona rasmiylashtirish vaqtincha to‘xtatildi.
中文翻译：塔什干机场暂时暂停了新手机的海关清关手续。
语法拆解 · GRAMMAR BREAKDOWN
地点状语：Toshkent aeroportida 中 -da 表示“在……”，相当于“在塔什干机场”。宾格：yangi telefonlarni 中 -ni 标记动作对象“新手机们”。复合名词：bojxona rasmiylashtirish 表示“海关清关/海关手续”。被动过去时：to‘xtatildi 由 to‘xtat-“停止”加被动过去时构成，表示“被暂停了”。
核心生词 · VOCABULARY
单词词性释义
aeroport名词机场
telefon名词手机；电话
bojxona名词海关
rasmiylashtirish名词办理；手续
vaqtincha副词暂时地
to‘xtatildi动词被暂停了
ENGLISH 商务英语 商务沟通 / 进度对齐
Before routing more context to the LLM, we compress tool outputs at the gateway to keep token costs and latency in check.
中文翻译：在将更多上下文送入大模型之前，我们在网关层压缩工具输出，以控制token成本与延迟。
句型与用法解析 · USAGE & STRUCTURE
时间状语：Before routing more context to the LLM 使用 before + doing，表示“在……之前”。核心动作：we compress tool outputs at the gateway 中 at the gateway 表示“在网关层”。目的状语：to keep ... in check 表示“控制住……”，其中 keep sth in check 是地道表达。
