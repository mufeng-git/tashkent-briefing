UZBEK 实用乌兹语 职场口语 / 协作
O‘zbekistonda o‘rtacha oylik ish haqi o‘n sakkiz foizga oshib, yetti million so‘mdan oshdi.
中文翻译：乌兹别克斯坦月平均工资增长了18%，超过了700万苏姆。
语法拆解 · GRAMMAR BREAKDOWN
句中 o‘rtacha oylik ish haqi 为名词短语“月平均工资”；数词后接格助词 -ga 表示变动幅度（“增长了18%”）；动词 oshib 是 oshmoq（增加）的副动词形式，表伴随动作；谓语 oshdi 为过去确定时，表示已达成的客观统计事实。
核心生词 · VOCABULARY
单词词性释义
o‘rtachaadj.平均的
ish haqin.工资、薪水
oshmoqv.增长、超过
foizn.百分比、百分点
ENGLISH 商务英语 商务沟通 / 进度对齐
To mitigate runtime vulnerabilities, enterprises must implement robust guardrails that intercept prompt injection and unauthorized tool execution before deployment.
中文翻译：为了防范运行时漏洞，企业在系统部署前必须落地稳健的防护护栏，以及时拦截Prompt注入和越权工具调用。
句型与用法解析 · USAGE & STRUCTURE
句首使用 To mitigate... 作目的状语；主干为 enterprises must implement...；名词 guardrails 后接 that 引导的限制性定语从句，从句中并列谓语动词 intercept 支配了两个宾语 prompt injection 和 unauthorized tool execution；末尾 before deployment 为时间状语。
