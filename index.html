UZBEK 实用乌兹语 职场口语 / 协作
Haydovchilar chorrahaga ellik metr qolganda chiziqni bossa, jarimaga tortilmaydi.
中文翻译：司机在距离十字路口五十米内压线行驶，将不会被处以罚款。
语法拆解 · GRAMMAR BREAKDOWN
句子主语为 Haydovchilar（司机们），时间/条件从句由 qolganda（在距离……还剩下时，由 qolmoq 加动名词及方位格词缀 -ganda 构成）引导，谓语为被动态否定形式 jarimaga tortilmaydi（不被处以罚金，动词词组 jarimaga tortmoq 的被动语态否定式）。
核心生词 · VOCABULARY
单词词性释义
chorraha名词十字路口，交叉路口
chiziq名词线条，标线
bosmoq动词踩踏，压（线）
jarima名词罚金，罚款
ENGLISH 商务英语 商务沟通 / 进度对齐
We must enforce a semantic control plane to mitigate security vulnerabilities and prevent prompt injection in multi-agent workflows.
中文翻译：我们必须部署语义控制平面，以缓解安全漏洞并防止多智能体工作流中的提示词注入。
句型与用法解析 · USAGE & STRUCTURE
情态动词 must 后接动词原形 enforce 表示必要措施；to mitigate... and prevent... 为双并列动词不定式短语作目的状语；术语 semantic control plane（语义控制平面）与 prompt injection（提示词注入）为现代Agent安全工程核心概念。
